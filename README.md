# 亀戸バス接近情報

亀戸七丁目から亀戸方面へ向かう **亀26・錦25・錦27** の都営バスを、到着が早い順に表示するPWAです。

## 表示
- あと約何分
- 現在何停前
- 現在の次停留所付近
- 遅延分数
- 20秒ごとの自動更新

## Renderへデプロイ
1. このフォルダ一式をGitHubの新規リポジトリへアップロードします。
2. Renderで **New → Blueprint** を選び、リポジトリを指定します。
3. 環境変数 `ODPT_ACCESS_TOKEN` に公共交通オープンデータセンターで発行したアクセストークンを登録します。
4. デプロイ後、URLをスマホで開きます。
5. iPhoneはSafariの共有ボタン →「ホーム画面に追加」です。

## ローカル起動（Windows）
```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
set ODPT_ACCESS_TOKEN=取得したトークン
python app.py
```

ブラウザで `http://127.0.0.1:5000` を開きます。

## 注意
到着分数は、都営バスの車両位置、対象停留所までの残り停留所数、APIの遅延情報から算出した目安です。道路状況などで実際の到着とずれることがあります。
